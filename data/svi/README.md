# CDC Social Vulnerability Index (SVI)

**Source**: [ATSDR CDC SVI Data](https://www.atsdr.cdc.gov/placeandhealth/svi/data_documentation_download.html)

**Usage**: We extract the SVI scores for census tracts in Maricopa County (Phoenix area) and perform a spatial join to map them to the 20 m² micro-grid cells.
